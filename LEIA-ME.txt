O QUE MUDA NA CÓPIA DE site/ EM RELAÇÃO AO ORIGINAL

- Arquivos do site (wp-content, wp-includes) apontam para caminho relativo.
- Links <a> para páginas copiadas apontam para a cópia; os demais seguem para o site
  (inclusive os relativos, como "/politica-de-privacidade/", que viram o endereço completo).
  Dados estruturados, canonical e og:url continuam com o endereço original.
- Rastreadores desligados, para que abrir a cópia não conte visita no analytics:
  Google Tag Manager, GA4, PostHog, Contentsquare, LinkedIn Insight, HubSpot tracking
  e Jetpack Stats. O código continua lá, marcado com
      type="text/plain" data-desligado-na-copia="rastreamento"
  e volta a funcionar se você tirar esses dois atributos.
- Ícones SVG usados como máscara CSS foram embutidos como data:, porque máscara
  não carrega de arquivo local.
- Swiper e AOS, que vinham de CDN, foram baixados para site/_cdn/.

PARA ATUALIZAR A CÓPIA (Terminal, dentro desta pasta)

    O WordPress do morada.ai devolve "503" para o seu IP se receber páginas demais em
    sequência (some em alguns minutos). Por isso as páginas são baixadas devagar, uma
    vez, e o script trabalha com os arquivos já baixados:

    mkdir -p /tmp/morada && cd /tmp/morada
    curl -s --rate 15/m -o home.html https://morada.ai/ -o morada-vendas.html https://morada.ai/morada-vendas/ -o morada-relacionamento.html https://morada.ai/morada-relacionamento/ -o conbral.html https://morada.ai/conbral/ -o direcional.html https://morada.ai/direcional/ -o fraiha.html https://morada.ai/fraiha/ -o conteudo.html https://morada.ai/conteudo/ -o blog.html https://morada.ai/blog/ -o quem-somos.html https://morada.ai/quem-somos/
    cd -
    node fonte/espelhar.mjs site fonte/originais https://morada.ai/=/tmp/morada/home.html https://morada.ai/morada-vendas/=/tmp/morada/morada-vendas.html https://morada.ai/morada-relacionamento/=/tmp/morada/morada-relacionamento.html https://morada.ai/conbral/=/tmp/morada/conbral.html https://morada.ai/direcional/=/tmp/morada/direcional.html https://morada.ai/fraiha/=/tmp/morada/fraiha.html https://morada.ai/conteudo/=/tmp/morada/conteudo.html https://morada.ai/blog/=/tmp/morada/blog.html https://morada.ai/quem-somos/=/tmp/morada/quem-somos.html

    python3 fonte/alteracoes.py
    Depois: git add -A && git commit -m "atualiza a cópia" && git push

    O alteracoes.py chama o node fonte/padrao-paginas.mjs (precisa do Node), que pode
    ser rodado sozinho e quantas vezes quiser. A Imprensa entra na atualização igual às
    outras (acrescente https://morada.ai/imprensa/ no curl e no espelhar.mjs).
    Parceiros e Morada OS não são espelhados: são páginas próprias da cópia e não são
    tocadas pela atualização.
